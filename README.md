# React-Native-TodoApp
📝 Todo App
A simple and responsive Todo application built with React Native and Expo, supporting both mobile and web platforms.

🚀 Features
Add, edit, and delete tasks

Mark tasks as completed

Web & mobile support (via Expo + React Native Web)

Clean and minimal UI

📦 Tech Stack
React Native

Expo

React Native Web

(Optional) AsyncStorage for local persistence
